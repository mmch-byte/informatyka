# Візуалізації з інформатики

Інтерактивні візуалізації до уроків інформатики (5, 6, 8 класи), опубліковані через GitHub Pages.

- Оглавлення з усіма посиланнями: https://mmch-byte.github.io/informatyka/
- Адреса візуалізації: `https://mmch-byte.github.io/informatyka/<клас>/<файл>.html`
- Папки: `5-klas/`, `6-klas/`, `8-klas/`
- Назва файлу: `NN-topic.html` (NN - номер теми, англійські слова)

Нову візуалізацію додаємо в папку класу й дописуємо рядок у список `DATA` у `index.html`.
